# AI Developer Companion

AI Developer Companion is a simple AI-based tool that helps developers understand and improve their code.

## About the Project

The main idea of this project is to provide a developer with useful information about their code in one place. The user can select a programming language and paste their code, and the AI analyzes it and provides:

- Code explanation
- Issues found in the code
- Suggestions for improvement
- Test cases
- Documentation

It can also identify when the submitted code does not match the selected programming language.

## Technologies Used

- HTML
- CSS
- JavaScript
- Node.js
- Express.js
- Google Gemini API
